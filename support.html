Frequently Asked Questions

How does the AI prediction work? / AI 预测如何工作？

The app combines deterministic longevity models with optional AI explanations. Estimates are for reference and are not clinically validated. On-device AI keeps analysis input local. A request you start reaches a configured provider only after cloud-processing consent; remote providers require your own API key, while a local HTTP server may work without one.

应用把确定性长寿健康模型与可选 AI 解读结合。估计结果仅供参考，尚未经临床验证。端侧 AI 会把分析输入留在本地。只有在你同意云端处理并主动发起请求后，数据才会发送给配置的服务商；远程服务需要你自己的 API Key，局域网 HTTP 服务可不填写。

Is my health data safe? / 我的健康数据安全吗？

Health data stays in Apple Health and the app's local container unless you explicitly export/share it or initiate a consented cloud request. The current release has no analytics, crash upload, advertising, or 100 Years hosted cloud service. See our Privacy Policy.

健康数据保存在 Apple 健康与 App 本地容器，除非你主动导出/分享或发起已获同意的云端请求。当前版本不运行分析统计、崩溃上报、广告或 100 Years 托管云服务。详见隐私政策。

How do I set up an API key? / 如何设置 API 密钥？

Go to Settings → Cloud Model Management, choose a remote provider, enter your own key, and validate it. A custom local HTTP server may be used without a key. Grant cloud AI processing consent before starting a request to either endpoint.

前往 设置 → 云端模型管理，选择远程服务商，填入自己的 API Key 并验证。自定义局域网 HTTP 服务可不填写密钥。向任一端点发起请求前，需开启云端 AI 数据处理同意。

What health data does the app need? / 应用需要哪些健康数据？

Additional authorized data can give the model more context, but it does not guarantee a more accurate estimate. Supported inputs include heart rate, blood pressure, sleep, workouts, steps, body measurements, and blood test results imported from reports.

获得授权的更多数据可为模型提供更多背景，但不保证估计更准确。支持的输入包括心率、血压、睡眠、运动、步数、身体测量数据，以及从报告导入的血液检查结果。

How do I buy, redeem, or restore Lifetime? / 如何购买、兑换或恢复完整版？

Go to Settings → Lifetime Access to buy the one-time product, open Apple's activation-code sheet, or restore an existing purchase. Apple processes every purchase and redemption; restoring creates no new charge.

前往 设置 → 完整版，即可一次性买断、打开 Apple 激活码兑换面板，或恢复已有购买。所有购买和兑换均由 Apple 处理；恢复不会产生新扣款。
