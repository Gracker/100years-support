隐私政策

活到百岁 (100 Years) · 版本 2026.09.30 · 最后更新：2026 年 9 月 30 日

摘要：你的健康数据默认保存在设备和 Apple 健康中；只有当你明确开启云端 AI 数据处理同意并主动发起分析时，披露的数据类别才会离开设备。当前版本不提供 100Years 托管云服务；获准的请求会从设备直接发送到你配置的端点，需要时使用你自己的 API 密钥。

1. 我们收集的信息

当前版本不运行分析统计、崩溃上报、广告或追踪收集。健康指标、个人资料、导入报告、日记、分析结果和偏好保存在 App 本地容器，或在授权后从 Apple HealthKit 读取。除你主动导出/分享或下文说明的获准云端 AI 请求外，这些数据不会离开设备。

当前 App 不上传：

  • 崩溃报告或性能遥测；
  • 广告标识符或追踪数据；
  • 健康记录到 100Years 运营的服务器。

2. 健康数据与 Apple HealthKit

活到百岁 集成 Apple HealthKit，读取你授权的健康指标，包括但不限于：

  • 心率、血压、血氧
  • 步数、步行距离、运动数据
  • 睡眠分析数据
  • 身体测量数据（身高、体重、体脂）
  • 营养数据

遵循 Apple HealthKit 使用规范：

  • 健康数据绝不会出售给广告平台、数据经纪商或任何第三方。
  • 健康数据绝不会用于广告或营销目的。
  • 健康数据绝不会存储在我们的服务器或我们控制的云存储上。
  • 你可以随时在 iOS 设置 → 健康 → 活到百岁 中控制应用可以访问的健康数据类别。

3. AI 分析

端侧 AI 不会把分析输入发送到设备外。只有当你明确开启云端 AI 数据处理同意、配置服务商并主动发起使用该服务商的分析时，App 才会把界面披露的数据类别从设备直接发送到该端点。远程服务商需要你自己的 API 密钥；局域网 HTTP 服务器可不填写密钥。完成后的 AI 工作会显示实际路由元数据。

  • 我们不会代理、截取或存储任何发送给 AI 服务商的数据。
  • 你的 API 密钥安全地存储在设备的 iOS Keychain 中。
  • 请查阅你所选 AI 服务商的隐私政策，了解他们如何处理数据。

4. 相机与相册

应用使用相机通过 OCR（光学字符识别）扫描健康/体检报告。扫描的图片在设备上处理，不会上传到任何服务器。相册访问用于导入报告和保存生成的分享图片。

5. 通知

经你许可后，应用会发送本地通知，用于运动提醒、分析完成通知和健康洞察。通知数据不会发送到外部服务器。

6. 购买

100Years 提供一个由 Apple StoreKit 处理的非消耗型永久买断商品。购买、App Store 激活码兑换、验证、恢复与退款均由 Apple 处理；我们无法访问你的支付信息，也不接收或自行验证激活码。

7. 数据存储与安全

  • 个人资料和分析结果使用 SwiftData 本地保存；偏好使用 App 本地 defaults 容器。
  • API 密钥存储在 iOS Keychain 中，使用 kSecAttrAccessibleWhenUnlockedThisDeviceOnly 保护级别。
  • 远程服务商请求使用 HTTPS/TLS。你自行配置的局域网 HTTP 端点不加密：经你同意并主动发起分析后，分析数据及你为该端点填写的 API 密钥会在局域网传输。iOS 可能请求“本地网络”权限。远程 HTTP 端点会被拒绝。

8. Apple Watch

配套 Apple Watch App 不直接读取 Apple 健康，而是通过 Apple WatchConnectivity 显示 iPhone 发来的受限健康快照。快照数据留在你的配对设备之间。

9. 儿童隐私

活到百岁及其健康估计适用于 18–120 岁成年人。超出范围的资料不能生成新的估计。既有本地数据不会自动删除；你可以在 App 内更正出生日期、导出或删除数据。

10. 第三方服务

应用可能集成以下第三方服务：

  • Apple HealthKit、WatchConnectivity 与 StoreKit——授权健康读取、配对设备同步、永久买断、激活码兑换、恢复与退款状态。Apple 隐私政策
  • AI 服务商（仅限你配置并主动调用的服务商）——云端分析。授予云端同意前，请先阅读所选服务商的政策。
  • Google LiteRT-LM——随 App 提供的端侧推理 runtime；本地使用不会传输分析数据。

11. 你的权利

你可以：

  • 随时在 iOS 设置中撤销 HealthKit 访问权限。
  • 在 App 账户设置中删除账户数据，或卸载 App 并移除其本地容器。
  • 随时在应用设置中移除你的 API 密钥。
  • 通过联系我们，了解我们可能收集的任何数据的相关信息。

12. 政策变更

我们可能不定期更新本政策。变更会使用版本号并在 App 内提示。现有用户可以暂缓接受并继续使用本地功能；未来云端数据发送或新购买前必须接受当前版本。
